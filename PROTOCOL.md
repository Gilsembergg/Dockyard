# DOCKYARD PROTOCOL

Version 0.1

---

## Philosophy

Dockyard protocol defines how an Agent must represent a machine for any Dockyard client. 
All agents (Linux, MacOS, Windows, ...) must output the exact same logical data format, independently from any OS. 
The client (iOS and MacOS, iPadOS and web in the future) should never depend on any OS' specific APIs.
